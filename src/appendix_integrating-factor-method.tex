\section{積分因子法}
微分方程式
\begin{gather}
  P(x,y)dx + Q(x,y)dy = 0
\end{gather}
に対して
\begin{gather}
  \ppar{P}{y} \neq \ppar{Q}{x}
\end{gather}
であっても、ある適当な関数$\grl(x,y)$が存在して、
\begin{gather}
  \ppar{(\grl P)}{y} = \ppar{(\grl Q)}{x} \label{eq:appendix-IF-intcond}
\end{gather}
が成り立つとき、あらたに関数$\hat{P}:=\grl P,\,\hat{Q}:=\grl Q$を用いて
\begin{gather}
  \hat{P}(x,y) dx + \hat{Q}(x,y) dy = 0 \\
  \ppar{\hat{P}}{y} = \ppar{\hat{Q}}{x}
\end{gather}
とできてこれは完全微分方程式である。
このときの関数$\grl(x,y)$を積分因子(Integrating Factor)といい、
積分因子を導入して解を得る方法を積分因子法という。
積分因子法はEq.~\eqref{eq:appendix-IF-intcond}について変形した$\grl(x,y)$に関する次の条件を満たせば
よいので、一階非線形常微分方程式においても用いられることがある。
\begin{gather}
  \ppar{\grl}{y}P + \ppar{P}{y}\grl = \ppar{\grl}{x}Q + \ppar{Q}{x}\grl
\end{gather}
ここで、$\grl=\grl(x)$である、すなわち\dm{\ppar{\grl}{y}=0}
であるような特殊な場合を仮定すれば
この$\grl(x,y)$についての偏微分方程式は$\grl(x)$についての常微分方程式
\begin{gather}
  \grl\biggl(\ppar{P}{y} - \ppar{Q}{x}\biggr) = \frac{d\grl}{dx}Q \\
  \Leftrightarrow
  \frac{1}{\grl}\frac{d\grl}{dx} = \frac{1}{Q(x,y)}\biggl(\ppar{P}{y} - \ppar{Q}{x}\biggr)
\end{gather}
となる（変数分離型）。
左辺は$y$に依存しない（$x$のみの式である）ので
右辺\dm{\frac{1}{Q}(P_{y} - Q_{x})}
も$y$に依存しない式となれば積分因子$\grl(x,y)$は$x$の関数$\grl(x)$としてよいということになる。

同様にして
\begin{gather*}
  \grl\biggl(\ppar{P}{y}-\ppar{Q}{x}\biggr)=-P\frac{d\grl}{dy} \\
  \Leftrightarrow
  \frac{1}{\grl}\frac{d\grl}{dy} = -\frac{1}{P(x,y)}\biggl(\ppar{P}{y}-\ppar{Q}{x}\biggr)
\end{gather*}
より、
右辺\dm{-\frac{1}{P}(P_{y} - Q_{x})}
が$x$に依存しない式となれば
これも変数分離型の常微分方程式であって、
積分因子$\grl(x,y)$は$y$の関数$\grl(y)$としてよいということになる。

一般に次のような公式が知られている。
\begin{spacing}{1.95}
  \begin{enumerate}[label=\textbf{\arabic*.}\hspace*{3pt}]
    \item \dm{ \frac{1}{Q(x,y)}\biggl(\ppar{P(x,y)}{y} - \ppar{Q(x,y)}{x}\biggr)}が$x$の関数 \\
    $\qquad\disp\Longrightarrow \grl(x) := \exp \left[ \int\frac{1}{Q}\biggl(\ppar{P}{y} - \ppar{Q}{x}\biggr)dx\right]$
    \item \dm{-\frac{1}{P(x,y)}\biggl(\ppar{P(x,y)}{y} - \ppar{Q(x,y)}{x}\biggr)}が$y$の関数 \\
    $\qquad\disp\Longrightarrow \grl(y) := \exp \left[-\int\frac{1}{P}\biggl(\ppar{P}{y} - \ppar{Q}{x}\biggr)dy\right]$
    \item \dm{\frac{P(x,y)}{y}}と\dm{\frac{Q(x,y)}{x}}が$xy$の関数 \\
    $\qquad\disp\Longrightarrow \grl(x,y) := \frac{1}{xP(x,y) - yQ(x,y)}$
  \end{enumerate}
\end{spacing}

% あるいは微分方程式を次のような一階線形常微分方程式に変形可能な場合を考える。
一般に積分因子は$x,\,y$の関数で簡単には求められないが、一階線形常微分方程式では
次のようにして積分因子を求められる。
\begin{gather}
  \frac{dy}{dx} + P(x)y = Q(x) \label{eq:appendix-IF-linearODE}
\end{gather}
斉次形（$Q(x) = 0$）のとき、これは変数分離形として解を得る。
非斉次形でかつ$Q$が$x$の関数のときは積分因子は一変数関数
$\grl(x)$として次のように求める。
両辺に$\grl(x)$をかけて
\begin{gather}
  \grl(x)\left\{ \frac{dy}{dx} + P(x)y \right\} = \grl(x)Q(x) \label{eq:appendix-IF-LODEgrl}
\end{gather}
としてこれが完全微分方程式となるための可積分条件
\begin{gather}
  \frac{1}{\grl}\frac{d\grl}{dx} = P(x) \label{eq:appendix-IF-linearODE-intcond}
\end{gather}
を解けば積分因子を得る。
また、Eq.~\eqref{eq:appendix-IF-LODEgrl}について次式
\begin{gather}
  \grl(x)\left\{ \frac{dy}{dx} + P(x)y \right\} = \frac{d}{dx}(\grl(x)y) \label{eq:appendix-IF-LHScond}
\end{gather}
を満たすので、積分因子をEq.~\eqref{eq:appendix-IF-linearODE-intcond}によって計算した上で、
\begin{gather}
  \frac{d}{dx}\bigl(\grl(x)y\bigr) = \grl(x)Q(x)
\end{gather}
を解けば良い。一応簡単に証明しておく。

% []: この辺微分とか条件とか怪しい
\begin{proof}
  Eq.~\eqref{eq:appendix-IF-LODEgrl}からEq.~\eqref{eq:appendix-IF-LHScond}を得ることを示す。
  Eq.~\eqref{eq:appendix-IF-LODEgrl}は
  \begin{gather}
    \grl(x)\bigl(Q(x) - P(x)y\bigr)dx - \grl(x)dy = 0
  \end{gather}
  と変形できて、
  これが完全微分形であるとき可積分条件は
  \begin{gather}
    \ppar{}{y} \Bigl(\grl(x)\bigl(Q(x) - P(x)y\bigr)\Bigr) = - \ppar{\grl(x)}{x}
  \end{gather}
  であって、左辺は$y$に依存しないのでたしかに積分因子$\grl(x)$が存在して
  \begin{align}
    \frac{d\grl}{dx}
    &= \ppar{}{y}\bigl(\grl(x)P(x)y\bigr) - \ppar{(\grl Q)}{y} \\
    &= \grl(x)P(x) \label{eq:appendix-IF-grlODE}
  \end{align}
  すなわち
  \begin{gather}
    \frac{1}{\grl}\frac{d\grl}{dx} = P(x) \label{eq:appendix-IF-howtogrl}
  \end{gather}
  を満たす。（この変数分離形の微分方程式を解くことによって積分因子を計算できる。）

  Eq.~\eqref{eq:appendix-IF-grlODE}の$\grl$に関する微分方程式の両辺を$y$倍して
  \dm{\grl\frac{dy}{dx}}を加えることで
  \begin{gather}
    \grl(x)\frac{dy}{dx} + \grl(x)P(x)y = y\frac{d\grl}{dx} + \grl(x)\frac{dy}{dx}
  \end{gather}
  を得る。この式は左辺を$\grl(x)$でくくり右辺を積の導関数と見れば、
  Eq.~\eqref{eq:appendix-IF-LHScond}と同値である。
\end{proof}

Eq.~\eqref{eq:appendix-IF-howtogrl}によって積分因子が得られれば、
\eqref{eq:appendix-IF-LODEgrl},\,Eq.~\eqref{eq:appendix-IF-LHScond}より
\begin{gather}
  \frac{d}{dx}\bigl(\grl(x)y\bigr) = \grl(x)Q(x)
\end{gather}
として、この微分方程式を解けば得られる。

以上の議論は$x$と$y$について対称性があるので、
入れ替えた形で積分因子を$\grl(y)$のように仮定することもある。
